Environment:
  Locale:
    LANG: Select the additional-help language. `zh_CN` (optionally followed by an encoding such as `.UTF-8`)
          selects Simplified Chinese; all other values select English.

  Display and interaction:
    PAGER: Pager command. A non-empty value is used without an availability check. If unset, ccdb uses
           `less` when it is available (`less` in no-color mode, otherwise `less -SR -S --rscroll='>'`).
   NOPAGER: When PAGER is unset, `true`, `1`, `yes`, or `y` disables pager detection and use.
     COLOR: `always` forces ANSI colors. `never`, `none`, `off`, `no`, `n`, `0`, or `false` disables them.
            Otherwise, color is enabled only when standard output is a terminal. If COLOR is unset and
            COLORFGBG reports a light background, ccdb automatically selects no-color mode.
        JQ: JSON formatter command. If unset, ccdb uses `jq` when it is available. A non-empty value is
            accepted without an availability check.
   TABSIZE: Number of spaces used to display a tab in tables. Must be a positive integer; default: 4.
    CURSOR: Cursor character used in the table search/command input. Only the first Unicode character is
            used; default: `█` (a space is selected automatically in Termux unless CURSOR is already set).
REVERSE_MOUSE: `true` or `false` reverses/restores mouse-wheel scrolling and overrides
               `Global::ReverseMouse` from `~/.ccdbrc`.
FOCUS_FOLLOW_MOUSE_SCROLLING: Set to `true` to move the focused row together with mouse-wheel scrolling.
NO_0xFE0F_EXPAND_EMOJI: Set to `true` when the terminal treats U+FE0F as zero-width. ccdb otherwise counts
                        U+FE0F as one extra cell. ccdb auto-selects a value for several known terminals
                        when this variable is unset.
NO_HIGHLIGHTER_LINE_COLOR_CODE: Set to `true` to suppress the ANSI sequences used for focused and selected
                                rows. This also removes the last visual indication of row focus/selection
                                when COLOR disables ordinary colors.
ENABLE_CLEAR_ON_SHRINK: Set to `true` to clear and redraw an interactive table after its content shrinks
                        enough to leave stale terminal lines.
CCDB_REVERT_TO_BACKGROUND: Set to `true` to render the active color scheme as background colors instead of
                           foreground colors.
SPECIFIED_BACKGROUND_RGB: Background used with foreground color schemes, in `R;G;B` form. Each component
                          is clamped to 0-255; default: `32;32;32`.

  Cache and custom color schemes:
DISABLE_CACHE_BEHAVIOR: Set to `true` to disable ccdb's reusable regex and frequency caches. This reduces
                        those memory caches at the cost of more CPU work; it does not disable every cache
                        or the custom color-scheme disk cache.
SCHEME_CACHE_SIZE: Sampling density used while generating a custom color-scheme cache; default: 32.
                   Generation evaluates the fractions `j/i` for `1 <= i <= SIZE` and `1 <= j < i`,
                   deduplicates equal samples, and adds the two endpoints.
SCHEME_CACHE_THREAD_COUNT: Worker batch threshold while generating a custom color-scheme cache; default:
                           the number reported by `std::thread::hardware_concurrency()`.
SCHEME_CACHE_DECIMAL_PRECISION: Decimal digits used for the custom scheme's offset and passed to the scheme
                                command as `precision`; default: 16.

  Network and TLS:
DISABLE_SERVER_CERTIFICATE_VERIFICATION: Set to `true` to disable HTTPS server-certificate verification
                                         (insecure). A valid `clash::sslCert` with `clash::sslVerify=on`
                                         re-enables verification for subscription-link requests.
SSL_CERTIFICATE: Path to a CA certificate/bundle tried before ccdb's built-in list of system CA paths.
          PREFIX: Prefix prepended to the built-in system CA paths (useful for environments such as Termux).
http_proxy / https_proxy: Proxy for matching HTTP/HTTPS subscription and upgrade requests, in
                          `scheme://host:port` form.
CCDB_SYNC_ADDRESS_BIND_TO: Interface used for CCDB's UDP group synchronization. Accepts `ADDR_ANY`, a local
                           interface name, or a local IPv4 address. If unset, ccdb normally selects the
                           interface used to reach the backend; an invalid explicit value disables UDP
                           group synchronization.

  Timing and diagnostics:
CCDB_LOG_REFRESH_INTERVAL: `get log` refresh interval in milliseconds; default: 100.
MIHOMO_PPROF_SECONDS: Duration in seconds requested by `get memory pprof profile` and `trace`; default: 15.
MIHOMO_PPROF_DBG: Value sent as the Mihomo pprof `debug` query parameter; default: 1.
DO_NOT_USE_ADDR2LINE: Set to `true` to stop `--feedBacktrace` from invoking `addr2line`.
SHOW_INPUT_TRACE: Set to `true` to print raw and encoded interactive key sequences to standard error.

  Exported by ccdb:
    CCDB: The full ccdb invocation. It is exported for child shell pipelines and is not read as a startup
          setting.

Interactive Table Controls (`get connections` and `get log`):
  Outside the search/command input:
    q / Q, Ctrl+C: Leave the table.
       Mouse click: Focus a row. Clicking the left or bottom scroll indicator jumps to that position.
       Mouse wheel: Scroll vertically (REVERSE_MOUSE changes the direction).
 Left/Right arrows: Scroll horizontally.
    Up/Down arrows: Scroll vertically.
          Home/End: Jump to the left/right edge.
       PageUp/Down: Scroll by approximately one page.
      Ctrl+Up/Down: Move the focused row by one row.
                 f: Scroll the table until the focused row is visible.
             Space: Toggle a persistent highlight on the focused row, then move focus down one row.
                 /: Open the search/command input.
             n / N: Move focus to the next/previous matching row after a search has been applied.

  In the search/command input:
              Enter: Apply the search, or execute a `:` command.
              Alt+E: Cancel the input and clear its contents.
 Left/Right, Home/End: Move the input cursor.
   Backspace/Delete: Delete text around the input cursor.
                Tab: Complete or cycle `:` command names in `get connections`.

  Search text is a case-sensitive ECMAScript regular expression matched against the concatenated displayed
  columns. It highlights matching text; it does not remove non-matching rows. Search navigation starts from
  the currently focused row.

  The k, p, f, arrow, Home/End, PageUp/Down, F1-F12, and Ctrl+Up/Down actions are configurable in the
  `[Shortcut]` section of `~/.ccdbrc` using ccdb's encoded key-sequence form. Mouse handling, q/Q,
  Ctrl+C, Space, /, n/N, and search-editor keys are fixed.

`get connections` Controls:
                 k: Close the focused connection.
                 p: Open the focused connection's raw Mihomo JSON through JQ (when available) and PAGER.
            F1-F12: Sort by columns 0-11. Press the key for the active sort column again to reverse order.

  Open the input with `/`, type one of the following commands (including the leading `:`), and press Enter:
    :hide LIST                 Hide columns for this table session. LIST accepts comma-separated indexes
                               and inclusive ranges, for example `0,2,4-6`.
    :closeAll                  Close every backend connection.
    :closeOnScreen             Close every connection in the current filtered table scope (not merely the
                               rows visible in the current terminal viewport).
    :filter COLUMN REGEX       Set an exclusion regex for a filterable column.
    :filterReverse             Toggle filter semantics between excluding and retaining matches.
    :clearFilters              Remove all active connection filters.
    :reverseChainParser        Toggle proxy-chain parsing and rebuild the connection frame.
    :pause / :resume           Pause or resume connection-frame updates.
    :sort COLUMN               Sort by a numeric column index.
    :sortReverse               Reverse the current sort order.
    :switchView                Switch to closed connections view.
    :setClosedConnectionBufferSpace Set the buffer space holding closed connections. Default is 128.

  Connection columns are: 0 Host, 1 Process, 2 Downloaded, 3 Uploaded, 4 Download speed, 5 Upload speed,
  6 Rule, 7 Time, 8 Source IP, 9 Destination IP, 10 Type, and 11 Chains. Filters are implemented for columns
  0, 1, 6, 8, 9, 10, and 11. In normal filter mode, a row matching any active filter is excluded.

`get log` Controls:
                 p: Toggle log fetching between paused and running. Newest entries are shown at the top.

`nload` Controls:
    q / Q, Ctrl+C: Leave the watcher.

Additional Info:

On first start, CCDB creates `~/.config/ccdb/client_private_key` (RSA-4096 PEM,
mode 0600) and `~/.config/ccdb/client_public_key` (a single line of base64
encoded SubjectPublicKeyInfo DER). On every CCDB instance that should receive
notifications, create `~/.config/ccdb/acceptable_clients` and put one entire
public-key line per trusted sender/recipient in it. For two-way communication,
add each other's `client_public_key` line to both clients' allowlists. Keep the
private key private; never put it into `acceptable_clients`. Missing allowlists
mean that no peers are trusted. Existing key pairs are reused, while an
incomplete or mismatched pair stops startup rather than silently changing identity.

The UDP hello advertises the public key. Messages use a fresh AES-256-GCM key,
wrapped with RSA-OAEP/SHA-256 separately for each trusted peer and signed with
RSA-PSS/SHA-256 by the sender. The encrypted envelope includes the sender key,
recipient key wraps, ciphertext, nonce, tag, timestamp, and signature. A receiver
checks its allowlist and the signature before processing any command or log sync.
The clocks of participating hosts should agree within two minutes.
